# starbucks-beverage-analysis-powerbi
Interactive Starbucks beverage analysis dashboard built using Microsoft Excel and Power BI to analyze beverage categories, calories, sugar, caffeine, and global presence.

# 📊 Project Overview
This project analyzes Starbucks beverage data using **Microsoft Excel and Power BI**.
The objective is to explore beverage categories, nutritional characteristics, caffeine and sugar levels, and Starbucks' global presence through an interactive business intelligence dashboard.
The final dashboard provides a simple and visual way to understand beverage characteristics and category-level patterns.

# 🛠️ Tools & Technologies
- Microsoft Excel
- Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization
- Business Intelligence

# 📌 Dashboard Highlights
The dashboard includes:
- Total Beverage Count
- Average Sugar Content
- Average Calories
- Average Caffeine
- Average Calories by Beverage Category
- Starbucks Global Presence
- Beverage Category Distribution
- Average Caffeine by Category
- Top 5 Highest-Caffeine Beverages
- Beverage category filtering
- Protein range filtering

# 🔍 Key Analysis Areas
1. Beverage Nutrition
Analysis of:
- Calories
- Sugar
- Caffeine
- Protein
 2. Beverage Categories
Comparison of different Starbucks beverage categories based on nutritional characteristics.
 3. Caffeine Analysis
Identification and comparison of beverage categories and individual beverages with higher caffeine levels.
4. Global Presence
Visualization of Starbucks presence across different markets/locations represented in the dataset.

# 📈 Key Insights
- Coffee has the highest average caffeine level among the analyzed beverage categories.
- Beverage categories show noticeable differences in their average calorie and caffeine levels.
- The dashboard highlights the top 5 beverages with the highest caffeine values, allowing quick comparison between individual products.

# 🎯 Project Objective
The main objective of this project was to practice **data cleaning, data analysis, DAX calculations, and interactive dashboard development** using Excel and Power BI.
This project demonstrates how raw beverage data can be transformed into an interactive dashboard that communicates meaningful business and product-level insights.
